## Perubahan

- Klien API (`PamApiClient`, `RemoteGmail.kt`): `POST /v1/gmail/connect/start`,
  `GET /v1/gmail/status`, `POST /v1/gmail/disconnect`. DTO hanya memuat status proyeksi:
  `connected`, `account_email_masked`, `scope`, `connected_at`, `last_sync_at`,
  `watch_expires_at`, `sync_state`, `last_error_code`. Tidak ada access/refresh token,
  authorization code, atau email penuh yang dipersist/ditampilkan klien.
- Domain/repository: `GmailLink`, `GmailLinkRepository`, `ServerGmailLinkRepositoryImpl`,
  binding Hilt `BackendModule`. Bila build tanpa backend, `isEnabled=false` dan layar
  menjelaskan keterbatasan (bukan tombol mati tanpa alasan).
- UI `GmailLinkScreen`: state belum tertaut, loading, terhubung (email masked + status sync +
  kedaluwarsa watch), error, backend nonaktif. Tombol **Tautkan Gmail** / **Ganti akun**
  membuka browser/Custom Tab ke `authorization_url`; **Putuskan** memakai dialog konfirmasi.
  Notice consent memisahkan consent Gmail, AI kategorisasi, dan AI analisis serta retensi
  satu tahun. Entry baru di Pengaturan: "Tautkan Gmail lewat browser".
- Deep link `pam://gmail/connected?status=success|error&reason=<safe_code>`: intent-filter
  `VIEW/BROWSABLE`, `launchMode=singleTop`, parsing di `MainActivity` (`onCreate` +
  `onNewIntent`), route nav `GmailLink`, banner hasil dan refresh status saat resume.
- Alur IMAP lama tetap utuh untuk jalur offline/demo; tidak ada penghapusan paksa di lane ini.
